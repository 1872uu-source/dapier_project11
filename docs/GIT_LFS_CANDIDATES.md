# Git LFS 검토 목록

검토 기준: 파일 크기 10 MiB 이상 또는 GitHub 일반 Git 파일 한도에 가까운 바이너리.

현재 전달 사본에서 기준 초과 파일은 발견되지 않았습니다. MuJoCo STL, URDF, XML, lockfile은 필수 실행 에셋/설정이므로 .gitignore에서 제외하지 않습니다. 각 STL은 개별 크기 기준 미만입니다.

학습 가중치, Ollama 모델, 체크포인트는 저장소에 넣지 않습니다. 추후 파일이 추가되면 라이선스와 재배포 가능성을 확인한 뒤 LFS 필요성을 별도 검토합니다. Git LFS 추적이나 업로드는 설정하지 않았습니다.
