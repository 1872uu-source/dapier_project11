# XLeRobot 웹앱 통합 구축 계획서

작성일: 2026-10-01  
문서 성격: 향후 추진 계획

## 1. 추진 목표

웹앱과 NOMI AI를 통해 XLeRobot을 조종하고, 목적지·물체를 찾아 이동하며 장애물을 피할 수 있는 통합 시스템을 구축한다. MuJoCo 시뮬레이션에서 기능을 검증한 뒤, 센서와 구동부 구성이 다른 실제 로봇 2대에 단계적으로 적용한다.

## 2. 추진 기능

### 2.1 AI 기반 통합 조종

- 웹앱에서 속도를 조절하고 키보드·조이스틱으로 주행한다.
- 텍스트와 음성으로 NOMI에 명령한다.
- 로컬 모델 Qwen + Hermes를 사용하고, 향후 고급 LLM으로 전환할 수 있도록 연결한다.
- 인식한 음성 문장을 확인·전송할 수 있게 하고, 이동 명령은 실행 결과를 사용자에게 알려준다.

### 2.2 목적지·물체 탐색 주행 및 장애물 회피

- 이름과 좌표를 등록한 장소로 이동한다.
- “책상으로 이동”처럼 물체 이름으로 요청하면 주변을 탐색해 대상을 인식하고, 접근 가능한 위치를 목적지로 계산한다.
- 책장 등 고정 장애물과 사람·고양이 등 이동 장애물을 구분해 경로를 계획하고 안전하게 회피한다.
- 센서 탐색 결과를 지도에 표시한다.
- 고정 장애물은 정적 지도에 기록하고, 이동 장애물은 현재 위치·이동 방향을 임시 정보로 추적한다. 관측이 끊긴 이동 장애물은 일정 시간 후 지도에서 제거한다.
- 인식 신뢰도가 낮거나 충돌 위험이 높을 때는 재탐색 또는 정지를 우선한다.

### 2.3 웹앱 화면과 조작 개선

- 기능을 상태 보기, 주행·지도, 로봇암, NOMI, 설정 화면으로 나눈다.
- 로봇암과 그리퍼 조종을 별도 화면으로 제공한다.
- 모바일에서는 자주 쓰는 조작을 우선 배치하고, 세부 정보는 별도 화면이나 접이식 영역으로 정리한다.

### 2.4 시뮬레이션 및 실제 로봇 연결

- MuJoCo를 공통 개발·검증 환경으로 사용한다.
- 좌표계, 경로 추종, 장애물 탐지, 정지 동작을 반복 검증한다.
- 하드웨어별 구동 방식과 센서 구성을 설정으로 분리해 두 종류의 로봇을 지원한다.

| 장비 | 계획된 구성 |
|---|---|
| 로봇 A | IKEA 트롤리 기반 4륜 개조형, 로봇암 및 JDAMR 연결, LiDAR 탑재 |
| 로봇 B | 4륜 개조형, LiDAR 제거, 카메라로 물체 위치 인식 |

실제 연결 전 각 장비의 바퀴 배치, 모터 드라이버, 엔코더, 속도 단위, 센서 좌표, 비상 정지 방식을 확인한다. 로봇 A는 LiDAR 기반 지도·장애물 기능을, 로봇 B는 카메라 기반 인식과 거리·위치 추정 기능을 중심으로 검증한다.

## 3. 추진 순서

1. **시뮬레이션 주행 기반 정리**: 좌표계와 이동 방향을 맞추고 목적지 주행·정지 기준을 확립한다.
2. **지도·탐지 기능 구축**: 고정 장애물 지도와 이동 장애물 임시 추적을 구현하고 회피를 검증한다.
3. **물체 기반 주행**: 물체 탐색, 위치 추정, 접근 가능한 목적지 계산을 연결한다.
4. **웹앱 구성 개선**: 주행·로봇암·NOMI·설정 화면과 모바일 UI를 정리한다.
5. **실제 로봇 적용**: 로봇 A와 B를 각각 저속·수동 조작부터 연결하고 센서별 기능을 확인한다.
6. **AI 모델 확장**: 로컬 Qwen + Hermes 연동을 구성하고, 이후 고급 LLM 연결을 추가한다.

## 4. 검증 및 완료 기준

- 목적지 주행이 직선·회전·대각선 경로에서 반복적으로 목표에 도착한다.
- 정적·동적 장애물을 구분해 지도에 표시하고, 충돌 위험이 있으면 감속·정지·우회한다.
- 물체 이름으로 요청한 경우 인식 대상과 이동 목적지가 사용자에게 표시된다.
- 음성·텍스트 명령, 속도 조정, 수동 조종, 로봇암 조종을 각 화면에서 사용할 수 있다.
- 두 실제 로봇에서 하드웨어·센서 프로필에 맞는 기능이 동작하고, 통신 장애나 비상 상황에서 정지한다.

## 5. 세부 결정이 필요한 항목

- 이동 장애물의 추적 만료 시간과 사람·동물 주변 안전 거리
- 물체 목적지를 물체 앞 접근점으로 계산하는 거리와 방향
- 지도 저장·초기화 방식과 여러 로봇 간 지도 공유 여부
- 실제 로봇별 모터·센서 사양과 구동 어댑터 설계
- 고급 LLM 공급자, API 연결 방식, 사용 비용
- 각 단계의 우선순위와 완료 일정
